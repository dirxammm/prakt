# Мультимедийная галерея

Учебный проект производственной практики ПП.05.01. Веб-приложение для хранения и просмотра изображений, видео и аудиозаписей, разделённых по категориям.

Клиент — HTML / CSS / JS. Сервер — Node.js + Express 5. База данных — MySQL 8. Авторизация — JWT. Серверная часть раздаёт одновременно API, клиентскую часть и загруженные файлы; поддерживает частичную отдачу (Range) для перемотки аудио и видео, ограничение числа неудачных попыток входа и очистку устаревших временных файлов при запуске.

## Структура

- `backend/` — серверная часть: `server.js`, `routes/`, `middleware/`, `config/`, `utils/`, `scripts/`.
- `frontend/` — клиентская часть: HTML-страницы, `css/style.css`, `js/api.js`.
- `database/` — DDL (`schema.sql`) и начальные данные (`seed.sql`).
- `uploads/` — хранилище файлов пользователей (`images/`, `videos/`, `audio/`, временный `tmp/`).
- `docs/` — проектная документация (`requirements.md`, `project-structure.md`, `api-plan.md`, `backend.md`, `database.md`, `user-guide.md`).
- `tests/` — план тестирования, тест-кейсы (`test-cases.md`, `test-cases-week3.md`, `test-cases-week4.md`), журнал замечаний.

## Запуск

1. Установить **Node.js 18+** и **MySQL 8**.
2. В `backend/` скопировать `.env.example` в `.env` и прописать параметры подключения к БД и секрет для JWT (длинная случайная строка от 16 символов).
3. Установить зависимости:
   ```bash
   cd backend
   npm install
   ```
4. Создать базу данных и таблицы, засеять категории:
   ```bash
   npm run db:init
   ```
5. Создать учётную запись администратора:
   ```bash
   npm run create-admin -- admin admin@mail.ru ВашПароль
   ```
6. (необязательно) Залить демонстрационные данные для показа:
   ```bash
   npm run seed-demo
   ```
   Создаёт двух пользователей (`demo_anna`, `demo_max`, пароль `Demo12345`) и ~11 материалов с реальными файлами. Удаление: `npm run seed-demo -- --reset`.
7. Проверить готовность и прогнать автотесты серверной части:
   ```bash
   npm run verify
   ```
   (включает `check` — состояние окружения, БД, uploads, и `smoke` — проверку всех маршрутов API).
8. Запустить сервер:
   ```bash
   npm start
   ```
9. Открыть в браузере: <http://localhost:3000>

Проверка состояния: <http://localhost:3000/api/health> возвращает `{"status":"ok"}`.

## Команды npm

| Команда | Назначение |
|---|---|
| `npm start` | Запуск сервера (production-режим) |
| `npm run dev` | Запуск с автоперезапуском (nodemon) |
| `npm run db:init` | Создание БД, таблиц и начальных категорий |
| `npm run create-admin` | Создание учётной записи администратора |
| `npm run seed-demo` | Загрузка демо-пользователей и материалов |
| `npm run check` | Проверка готовности окружения, БД, uploads |
| `npm run smoke` | Автотест маршрутов API |
| `npm run verify` | Полная проверка: `check` + `smoke` |
