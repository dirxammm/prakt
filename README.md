# Мультимедийная галерея

Учебный проект производственной практики ПП.05.01. Веб-приложение для хранения и просмотра изображений, видео и аудиозаписей, разделённых по категориям.

Клиент — HTML/CSS/JS. Сервер — Node.js + Express 5. База данных — MySQL 8. Авторизация — JWT.

## Структура

- `backend/` — серверная часть (API, авторизация, обработка загрузок).
- `frontend/` — клиентская часть (HTML/CSS/JS).
- `database/` — DDL и начальные данные (`schema.sql`, `seed.sql`).
- `uploads/` — хранилище загружаемых файлов.
- `docs/` — проектная документация (требования, план API, структура).
- `tests/` — план тестирования, тест-кейсы, журнал замечаний.

## Запуск

1. Установить **Node.js 18+** и **MySQL 8**.
2. В `backend/` скопировать `.env.example` в `.env` и прописать параметры подключения к БД и секрет для JWT.
3. Установить зависимости:
   ```bash
   cd backend
   npm install
   ```
4. Создать базу данных и таблицы, засеять категории:
   ```bash
   npm run db:init
   ```
5. Создать учётную запись администратора:
   ```bash
   npm run create-admin
   ```
6. Запустить сервер:
   ```bash
   npm start
   ```
7. Открыть в браузере: <http://localhost:3000>

Сервер раздаёт одновременно API (`/api/…`), клиентскую часть (`frontend/`) и загруженные файлы (`uploads/`).
