# План API — «Мультимедийная галерея»

Базовый адрес: `http://localhost:3000`. Формат обмена — JSON (загрузка материала — `multipart/form-data`).
Авторизация: заголовок `Authorization: Bearer <токен>`. Ошибки: `{ "error": "описание" }`.

| Метод и путь | Доступ | Назначение |
|---|---|---|
| GET /api/health | все | проверка работы сервера и базы данных |
| POST /api/auth/register | все | регистрация (login, email, password) |
| POST /api/auth/login | все | вход (login, password), ответ: token и user |
| POST /api/auth/logout | авторизованный | выход (токен удаляется на клиенте) |
| GET /api/users/me | авторизованный | данные пользователя и его материалы |
| GET /api/categories | все | список категорий |
| GET /api/materials | все | список материалов; параметры `type` (image, video, audio), `category` (номер категории), `q` (часть названия) |
| GET /api/materials/:id | все | один материал |
| POST /api/materials | авторизованный | добавление: title, description, category_id, type, file или link (видео) |
| DELETE /api/materials/:id | автор или админ | удаление материала и файла |
| GET /api/admin/users | админ | список пользователей с количеством материалов (`materials_count`) |
| GET /api/admin/materials | админ | все материалы; параметры `type` и `q` |
| DELETE /api/admin/materials/:id | админ | удаление любого материала |

Типы материалов: `image`, `video`, `audio`.
Форматы и размеры: изображения JPG/PNG/WEBP до 10 МБ, видео MP4 до 100 МБ, аудио MP3/WAV до 20 МБ.
Загруженные файлы доступны по адресу из поля `file_path` (`/uploads/...`), поддерживается частичная отдача (Range) для перемотки.

## Коды ответов

| Код | Когда |
|---|---|
| 200, 201 | успех (201 — создано) |
| 400 | ошибка данных: пустые поля, неверный формат, слишком большой файл, неверный фильтр |
| 401 | нет токена, токен недействителен, неверный логин или пароль |
| 403 | недостаточно прав (чужой материал, административный маршрут) |
| 404 | материал или маршрут не найден |
| 409 | логин или e-mail уже заняты |
| 413 | слишком большой запрос |
| 429 | слишком много неудачных попыток входа (10 за 10 минут) |
| 500 | внутренняя ошибка сервера |
