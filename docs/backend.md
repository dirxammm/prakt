# Серверная часть и база данных

Технологии: Node.js, Express 5, MySQL (MariaDB), JWT-авторизация, bcrypt, Multer.
Один сервер отдаёт и API, и страницы сайта (папка `frontend/`), и загруженные файлы (`uploads/`).

## Запуск с нуля

```
cd backend
npm install
copy .env.example .env          (впишите пароль MySQL и любую длинную строку в JWT_SECRET)
npm run db:init                 (база, таблицы, категории, индексы; безопасно запускать повторно)
npm run create-admin -- admin admin@mail.ru ВашПароль
npm start                       (сайт: http://localhost:3000)
```

## Проверки и демо-данные

| Команда | Что делает |
|---|---|
| `npm run check` | проверяет окружение, подключение к БД, таблицы, категории, файлы в `uploads`; `npm run check -- --fix` удаляет лишние файлы |
| `npm run smoke` | автотест: сам запускает сервер, проверяет все маршруты и сообщения об ошибках (около 80 проверок), после себя всё удаляет |
| `npm run verify` | `check` и `smoke` подряд: итоговая проверка перед сдачей |
| `npm run seed-demo` | добавляет демо-пользователей и 11 материалов (картинки и звук создаются сами); `npm run seed-demo -- --reset` удаляет их |

Демо-пользователи: `demo_anna` и `demo_max`, пароль `Demo12345`.

## Структура

```
backend/
├── server.js               запуск, заголовки безопасности, обработка ошибок
├── config/db.js            пул соединений MySQL
├── middleware/             auth.js (токен, роль), upload.js (приём и проверка файлов)
├── routes/                 auth, users, categories, materials, admin
├── utils/                  files.js, filters.js (поиск и фильтры), loginLimiter.js, media.js
└── scripts/                init-db, create-admin, check, smoke-test, seed-demo
database/                   schema.sql (структура), seed.sql (категории)
```

## Безопасность

- пароли хранятся только в виде хэша bcrypt (не более 72 байт);
- токен JWT, срок действия 7 дней; секрет только в `.env`, без него сервер не запускается;
- не более 10 неудачных попыток входа за 10 минут (ответ 429);
- все запросы к базе с параметрами (защита от SQL-инъекций), символы `%` и `_` в поиске экранируются;
- проверка формата, размера и соответствия типу для каждого файла; файлы получают случайные имена;
- временные и лишние файлы удаляются при любых ошибках, устаревшие чистятся при запуске;
- заголовки `X-Content-Type-Options: nosniff`, `X-Frame-Options`, `Referrer-Policy`.

## Что показать и сказать в итоговом видео (серверная часть и БД)

1. Запуск: `npm start` в терминале («MySQL: подключение установлено», «Сервер запущен»).
2. В phpMyAdmin: три таблицы `users`, `categories`, `materials`, вкладка «Дизайнер» со связями, пять категорий.
3. Зарегистрировать пользователя на сайте и показать в таблице `users` хэш пароля вместо пароля.
4. Добавить изображение, аудио и видео, показать новые строки в `materials` и файлы в папке `uploads`.
5. Удалить материал и показать, что строка и файл исчезли.
6. Показать ошибки с понятными сообщениями: неверный пароль, пустая форма, неверный формат файла, несуществующий материал, несуществующая страница.
7. Закончить командой `npm run verify`: итог «пройдено … провалено 0».
