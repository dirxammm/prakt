# Функциональные требования

## 1. Общие сведения
Веб-приложение «Мультимедийная галерея» предназначено для хранения и просмотра мультимедийных материалов (изображений, видео, аудио), разделённых по категориям. Авторизованные пользователи могут добавлять собственные материалы, искать и фильтровать их. Администратор управляет пользователями и всеми материалами.

## 2. Роли пользователей
- **Гость** — просматривает главную страницу, галерею и отдельные материалы.
- **Пользователь** — всё перечисленное выше, плюс добавление и удаление собственных материалов, личный кабинет.
- **Администратор** — всё перечисленное выше, плюс просмотр всех пользователей и удаление любых материалов.

## 3. Функциональные требования
### 3.1 Регистрация и авторизация
- Регистрация по логину, e-mail и паролю.
- Валидация: логин 3–30 символов (латиница, цифры, «_»), корректный e-mail, пароль не короче 6 символов, уникальность логина и e-mail.
- Пароль хранится только в виде хэша (bcrypt).
- Авторизация — JWT, время жизни токена 7 дней.
- Выход — удаление токена на клиенте.

### 3.2 Личный кабинет
- Отображение данных пользователя (логин, e-mail, роль, дата регистрации).
- Список добавленных пользователем материалов.
- Удаление своих материалов.

### 3.3 Добавление материалов
- Поля: название (до 150 символов), описание (до 2000), категория, тип (изображение/видео/аудио), файл или ссылка (для видео).
- Форматы: JPG, PNG, WEBP; MP4; MP3, WAV.
- Лимиты: изображение 10 МБ, аудио 20 МБ, видео 100 МБ.
- Доступно только авторизованным пользователям.

### 3.4 Галерея и просмотр материала
- Общая галерея материалов в виде карточек с превью.
- Фильтрация по типу материала.
- Поиск по подстроке в названии (клиентский).
- Отдельная страница материала с воспроизведением (`<img>`, `<video>`, `<audio>`) и описанием.

### 3.5 Удаление материала
- Автор может удалить свой материал.
- Администратор может удалить любой материал.
- Файл одновременно удаляется с диска.

### 3.6 Административная страница
- Только для роли `admin`.
- Таблица пользователей и таблица всех материалов.
- Удаление любого материала.

### 3.7 Адаптивный интерфейс
- Корректное отображение при разрешениях 1200, 768 и 480 px.
- Меню на мобильных сворачивается в кнопку-«гамбургер».

## 4. Нефункциональные требования
- Клиент — HTML5/CSS3/JS, без тяжёлых фреймворков.
- Сервер — Node.js + Express 5.
- БД — MySQL 8.
- Все страницы с текстом или иллюстрацией оформлены единообразно.
- Готовый проект запускается одной командой `npm start` (сервер раздаёт и API, и клиентскую часть).
