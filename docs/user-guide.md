# Руководство пользователя и сценарий видеопрезентации

Документ описывает запуск готового проекта «Мультимедийная галерея» и пошаговый сценарий для записи итогового видео (5–10 минут).

## 1. Запуск проекта «с нуля»

```bash
cd backend
npm install                                      # установка зависимостей
cp .env.example .env                             # заполнить DB_* и JWT_SECRET
npm run db:init                                  # создать БД, таблицы, засеять категории
npm run create-admin -- admin admin@mail.ru СильныйПароль   # создать админа
npm run seed-demo                                # (для демонстрации) залить 11 материалов и 2 демо-пользователя
npm run verify                                   # полная проверка окружения, БД, маршрутов
npm start                                        # запуск сервера
```

Открыть в браузере: <http://localhost:3000>. Проверить состояние: <http://localhost:3000/api/health>.

## 2. Полный функционал приложения

### 2.1 Главная страница
- Крупный герой-заголовок «Пространство для вашей коллекции.»
- Кнопка «Открыть галерею» ведёт в каталог; «Создать аккаунт ›» — на регистрацию.
- Лента «Последние материалы» (до 8 карточек).

### 2.2 Регистрация и авторизация
- Валидация логина (3–30 символов латиницы, цифр и `_`), e-mail, пароля (не менее 6 символов, до 72 байт).
- Хранится только хэш пароля (bcrypt).
- JWT-токен на 7 дней; выход очищает токен в localStorage.
- Защита: не более 10 неудачных попыток входа за 10 минут (HTTP 429).

### 2.3 Личный кабинет
- Таблица аккаунта: логин, e-mail, роль, дата регистрации.
- Сетка добавленных материалов с кнопкой удаления (модальное подтверждение → toast).

### 2.4 Добавление материала
- Поля: название, описание, категория, тип (изображение / видео / аудио), файл или ссылка (для видео).
- Форматы: JPG, PNG, WEBP до 10 МБ; MP4 до 100 МБ; MP3, WAV до 20 МБ.
- Все ошибки сервера (несоответствие формата и типа, превышение размера, неверная ссылка) выводятся как понятные сообщения.

### 2.5 Галерея, фильтры, поиск
- Пилюли фильтра по типу: Все / Изображения / Видео / Аудио.
- Селект «Все категории» для фильтра по категории.
- Поле поиска по подстроке в названии, запрос уходит с задержкой 350 мс.
- Все три параметра сочетаются и попадают в URL — ссылкой можно поделиться.

### 2.6 Страница материала
- Изображения: клик — открывается lightbox (×, фон, Esc).
- Видео: HTML5-плеер с перемоткой (сервер поддерживает Range).
- Видео по ссылке: кнопка «Открыть видео».
- Аудио: HTML5-плеер с перемоткой.
- Клик по категории → переход в галерею, отфильтрованную по этой категории.
- Внизу — блок «Ещё в категории …» (до 4 похожих материалов).

### 2.7 Административная страница (`/admin.html`)
- Таблица пользователей с бейджами ролей и колонкой «Материалов».
- Таблица всех материалов с фильтром по типу и поиском.
- Удаление любого материала (модалка + toast).

### 2.8 Адаптивность
- Проверено на 1440 / 1024 / 768 / 480 / 390 / 320 px.
- Меню сворачивается в бургер на мобильных.
- Админ-таблицы прокручиваются горизонтально на узких экранах.
- Длинный логин в шапке обрезается троеточием.

## 3. Сценарий итогового видео (5–10 минут)

Длительность каждого эпизода — ориентировочная; главное — показать работу функций.

| № | Эпизод | Что показать | ~длительность |
|---|---|---|---|
| 1 | Запуск проекта | Терминал: `npm start`, сообщения «MySQL: подключение установлено», «Сервер запущен: http://localhost:3000» | 20 с |
| 2 | Главная страница | Открыть `/`, показать герой-блок и ленту «Последние материалы» | 15 с |
| 3 | Регистрация пользователя | Открыть `/register.html`, заполнить, проверить валидацию, зарегистрировать | 30 с |
| 4 | Авторизация | Выход и повторный вход в этот же аккаунт | 15 с |
| 5 | Личный кабинет | Открыть `/profile.html`, показать данные пользователя | 15 с |
| 6 | Общая галерея | Открыть `/gallery.html` — сетка материалов, карточки | 15 с |
| 7 | Добавление изображения | Форма: название, описание, категория «Фотографии», файл JPG — загрузка | 40 с |
| 8 | Просмотр изображения | Переход на страницу материала, клик по картинке → lightbox | 20 с |
| 9 | Добавление видео | Форма: тип «Видео», ссылка `https://…mp4` — добавление | 25 с |
| 10 | Воспроизведение видео | Открыть добавленный материал (или демо-видео), запуск, перемотка | 25 с |
| 11 | Добавление аудио | Форма: тип «Аудио», MP3-файл — добавление | 25 с |
| 12 | Воспроизведение аудио | Открыть, запуск, пауза, перемотка | 20 с |
| 13 | Работа категорий | На странице материала клик по категории → галерея с фильтром | 15 с |
| 14 | Работа поиска | В галерее ввести «гор» — список фильтруется | 15 с |
| 15 | Работа фильтров | Переключить фильтр «Аудио», выбрать категорию «Музыка» | 15 с |
| 16 | Удаление материала | На странице материала или в кабинете — кнопка «Удалить», модалка, toast | 20 с |
| 17 | Административная страница | Войти admin'ом, показать таблицу пользователей (бейджи, materials_count) и таблицу материалов, фильтр, удаление | 50 с |
| 18 | Мобильный вид | Открыть DevTools, переключить на 390 × 844: главная, галерея, меню-бургер | 30 с |
| 19 | Команда проекта | Кратко: кто что делал (Дадаев — backend+БД; Участник 1 — frontend; Участник 3 — тестирование + документация + мультимедиа + помощь в объединении) | 20 с |

**Итого:** ~7 минут.

## 5. Для записи видео рекомендуется

1. Перед запуском выполнить `npm run seed-demo` — это создаст двух пользователей и 11 материалов (чтобы галерея выглядела наполненной).
2. Иметь под рукой логины:
   - Администратор: `admin / <ваш пароль>`.
   - Демо-пользователи: `demo_anna / Demo12345`, `demo_max / Demo12345`.
3. Для демонстрации регистрации использовать новый уникальный логин (например, `demo_viewer`).
4. Браузер открыть в приватном окне с размером 1366 × 768 или 1920 × 1080 — так интерфейс выглядит одинаково у всех зрителей.
5. Запись вести одним дублем, без склеек; говорить от третьего лица («в проекте реализовано», «пользователь нажимает»).
