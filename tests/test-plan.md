# План тестирования — «Мультимедийная галерея»

## 1. Цели тестирования
- Убедиться, что реализованный функционал соответствует требованиям технического задания.
- Выявить и зафиксировать дефекты до демонстрации проекта.
- Проверить корректность обработки ошибок (неверный ввод, превышение лимитов, попытка несанкционированного доступа).

## 2. Объект тестирования
Веб-приложение «Мультимедийная галерея». Клиентская часть — HTML/CSS/JS. Серверная часть — Node.js + Express. База данных — MySQL 8. Авторизация — JWT.

## 3. Уровни и виды тестирования
- **Функциональное** — проверка каждой функции по чек-листу (регистрация, авторизация, добавление/просмотр/удаление материала, личный кабинет, галерея, фильтры, поиск, админ-панель).
- **UI/вёрстка** — проверка отображения страниц, адаптивности (1200 px, 768 px, 480 px).
- **Негативное** — проверка корректной обработки некорректных данных и попыток обхода.
- **Интеграционное** — проверка связки frontend ↔ backend ↔ БД.
- **Ручное** — все виды выполняются вручную, с фиксацией результатов в журнале.

## 4. Среда тестирования
- Операционная система: Windows 10 / Windows 11.
- Браузеры: Chrome 128+, Firefox последний, Edge последний.
- Разрешения экрана: 1920×1080 (desktop), 768×1024 (tablet), 375×667 (mobile).
- Backend: localhost:3000 (один `npm start` раздаёт API и статические файлы).
- База данных: MySQL 8.0 локально.

## 5. Критерии прохождения
- Все обязательные тест-кейсы завершены успешно.
- Критических дефектов нет.
- Все выявленные замечания зафиксированы в журнале (`tests/bug-journal.md`) и либо устранены, либо запланированы к устранению.

## 6. График
- 2-я неделя — тестирование регистрации, авторизации, личного кабинета, добавления материала.
- 3-я неделя — тестирование галереи, страницы материала, поиска, фильтрации, мультимедиа-плееров, админ-панели.
- 4-я неделя — финальная регрессия и подготовка видеопрезентации.
